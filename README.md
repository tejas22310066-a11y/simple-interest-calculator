# Simple Interest Calculator

This project is a simple Bash script that calculates Simple Interest.

## 📌 Purpose
The purpose of this project is to help users calculate simple interest easily using a command-line script.

## 🧮 Formula Used
Simple Interest = (Principal × Rate × Time) / 100

## ⚙️ How It Works
The script takes three inputs from the user:
- Principal amount (P)
- Rate of interest (R)
- Time period (T)

It then applies the formula and displays the result.

## ▶️ How to Run
Run the script using:
bash simple-interest.sh

## 💡 Example
Input:
Principal = 1000  
Rate = 5  
Time = 2  

Output:
Simple Interest = 100
